# Demo Sample Data

These files are **synthetic demo fixtures** explicitly labelled as **DEMO DATA** for testing Phase 2 ingestion:

- `demo_subcontract_sample.pdf` — 2-page synthetic subcontract PDF (**DEMO DATA**, not a real contract)
- `demo_boq_sample.xlsx` — 2-sheet synthetic BOQ Excel workbook (**DEMO DATA**, includes merged headers, blank rows, and intentionally missing quantities/rates)

## Rules for Demo Files

- Always upload sample files with **"Label upload as DEMO DATA"** enabled (`is_demo=true`) so records display the **DEMO DATA** badge in the UI.
- Never present demo rates, quantities, clauses, or approvals as real project contract data.
